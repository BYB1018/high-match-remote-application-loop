# High-Match Remote Application Loop

用母版简历与证据库筛选远程岗位，基于真实经历定制材料，以小批量投递和回复数据迭代。

## 内容

- `SKILL.md`：Skill 指令
- `test-prompts.json`：6 条路由测试题
- `test-results.md`：历史测试记录

核心原则：先核查地区、时区、合同、语言和硬资格，再改写真实材料；禁止伪造经历、冒充候选人或自动提交。
