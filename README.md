# High-Match Remote Application Loop

## 中文

用母版简历与证据库筛选远程岗位，基于真实经历定制材料，以小批量投递和回复数据迭代。

核心原则：先核查地区、时区、合同、语言和硬资格，再改写真实材料；禁止伪造经历、冒充候选人或自动提交。

## English

Screen remote roles with a master resume and evidence library, tailor applications from real experience, and iterate using small-batch response data.

Core principle: verify location, time zone, contract, language, and hard qualifications before rewriting truthful materials. Do not fabricate experience, impersonate a candidate, or auto-submit applications.
